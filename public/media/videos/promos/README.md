# Promotional videos

- Banners/sliders: wide (~16:9 or wider). Sidebar ads: square (~1:1). Muted +
  loopable, ≤ 1080p, a few MB.
- Drop the file (e.g. `new-drop-banner.mp4`, `ad-glueless-square.mp4`) and tell
  me the section it belongs in — I wire it.
