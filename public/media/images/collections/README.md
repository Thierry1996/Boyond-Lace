# Shop-by-collection images

Card images for the **Shop-by-collection rail** (home, right under the hero) and
the collection circles on `/shop-by-intentions`.
Served at **`/media/images/collections/<file>`**.

## Drop convention
Name each file by the collection's **slug** (its `/collections/‹slug›` URL), so I
can auto-wire it to that collection's card — e.g. `glueless-wigs.webp`.

- `.webp` preferred; `.jpg`/`.png` fine. Roughly **square (1:1)** reads best in
  the rail; ≤ ~1600px, compressed.
