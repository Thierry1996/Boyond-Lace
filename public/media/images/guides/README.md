# Size, length & reference guide images

Drop **size charts, hair-length charts, measurement diagrams, cap-size guides,
lace-size diagrams, colour/shade rings** and similar reference art here.
Served at **`/media/images/guides/<file>`**.

These feed the **Size Guide page** (`/support/size-guide`), the **Learn** hub,
and length/measurement references on product pages.

## Format
- Charts/diagrams: `.png` or `.svg` keep text crisp; `.webp`/`.jpg` fine for photos.
- Keep the long edge ≤ ~2000px and compress. Landscape charts read best full-width.

## Suggested filenames (use whichever apply)
| File | Used for |
|---|---|
| `length-chart.jpg` | Hair-length chart (inches → on-body length) |
| `size-chart.jpg` | Full size chart |
| `how-to-measure.jpg` | Head-measuring diagram |
| `cap-size-guide.jpg` | Cap size (petite / average / large) |
| `lace-size-guide.jpg` | Lace/parting sizes (13x4, 13x6, 5x5…) |
| `length-guide-<texture>.jpg` | Per-texture length (curl shrinkage differs) |

Drop them in, tell me they're in and which page/section each belongs on, and I'll
wire them (size-guide page, PDP length reference, or Learn). If you're not sure
where one goes, just drop it and I'll place it sensibly.
